Install Ascent on Your Chromebook

⚡ Instant 1-Click Chromebook Install Ready

Chrome has verified the manifest & service worker. Click below to install Ascent to your Chromebook Shelf:

Way 1: Install Using Your sw.js, manifest.json & background.js Files

1. Open the Files app on your Chromebook and create a folder named Ascent.
2. Put this HTML file, manifest.json, background.js, and sw.js inside that Ascent folder.
3. Open Chrome, type chrome://extensions in the top address bar, and press Enter.
4. Turn ON Developer mode (top-right switch), click Load unpacked (top-left), and select your Ascent folder.
5. Type ascent + Space + Enter in Chrome's address bar (or click the 🧩 icon) to open Ascent as a standalone Chromebook window!

Way 2: Install Directly from Chrome Menu / Address Bar

Click the ⋮ (three dots) menu at the top-right of Chrome → Save and share (or More tools) → click Install page as app... (or Create shortcut... → check "Open as window").
